## Platform

web

Настольное приложение на Tauri v2 (Windows — основная цель, сборки есть и для macOS и Linux). Интерфейс — веб-страница в окне без системной рамки, минимальный размер 1150×720.

## Users

Смешанная аудитория игроков серверов FenixCraft: от новичков, которые впервые ставят моды и играют в режиме «Пиратка», до опытных игроков, которые настраивают память, Java, шейдеры и смотрят консоль. Главное действие доступно сразу, продвинутые настройки убраны глубже, но не спрятаны.

Отдельная роль — администратор проекта BloodRayT: ведёт сервер сборок, новости сообщества VK и стримы на Twitch.

## Product Purpose

Официальный лаунчер Minecraft проекта FenixCraft. Он скачивает клиент, Java и моды выбранной сборки, проверяет файлы по контрольным суммам и запускает игру одной кнопкой. Ванильная версия после первой загрузки работает без интернета.

Успех: игрок без ручной настройки попадает на сервер FenixCraft с правильной сборкой, остаётся рядом с сообществом и видит магазин привилегий.

## Positioning

Лаунчер синхронизирован с собственным сервером сборок FenixCraft: набор модов у всех игроков одинаковый, лишние моды удаляются, а при недоступном сервере сборок лаунчер честно показывает «Технические работы» вместо запуска с устаревшими файлами. Вместе с этим он объединяет в одном окне вход («Пиратка» или «Лицензия» Microsoft), новости, стримы, Discord и донат именно этого проекта.

## Operating Context

- Сборки: Vanilla 26.3, Vanilla 26.3 + Iris, NeoForge 1.21.1 (сервер FenixTech), NeoForge 1.21.1 + Iris, NeoForge 26.2 + Iris. Список задан в `src-tauri/core/src/config.rs` и `src/builds.js`.
- Серверы: FenixCraft `play.fenixcraft.ru` (Vanilla 26.3), FenixTech `tech.fenixcraft.ru` (NeoForge 1.21.1). На «пиратке» вход на сервер через `/register` и `/login`.
- Сервер сборок: FastAPI-бекенд по адресу `http://fenixcraft.ru/api/launcher` (пока только HTTP), раздаёт файлы из `storage/<сборка>/`.
- Сообщество: VK `vk.ru/fenixcraft`, Twitch `bloodrayt`, Discord `discord.gg/UM7CXyN`, магазин `fenixcraft.trademc.org`.
- Игрок открывает лаунчер перед каждой игровой сессией; во время игры лаунчер работает в фоне.

## Capabilities and Constraints

- Вход: «Пиратка» (ник 3–16 символов латиницей) и «Лицензия» через Microsoft; токен хранится в системном хранилище Windows.
- Отдельная папка для каждой сборки (`instances/<сборка>`), общая папка игры меняется в настройках.
- 3D-персонаж со скином игрока, анимации и загрузка своего скина PNG 64×64. Скин показывается только в лаунчере; в игре его видно лишь при плагине скинов на сервере.
- Новости VK и история релизов GitHub с кешем на случай отсутствия сети; Twitch-плеер и чат внутри лаунчера.
- Обновления лаунчера только из GitHub Releases этого репозитория.
- CSP разрешает скрипты только из самого приложения: библиотеки лежат локально (`src/vendor`), шрифт Inter тоже локальный.
- Язык интерфейса сейчас русский; нужны ли другие языки — не решено.

## Product Principles

1. Одна кнопка до игры: выбор сборки и «Играть» всегда на виду, всё остальное не мешает этому пути.
2. Честность о состоянии: без сети, при техработах или ошибке лаунчер прямо говорит, что происходит и что делать.
3. Одинаковые файлы у всех: синхронизация сборок важнее свободы ставить свои моды в серверные сборки.
4. Сообщество рядом: новости, стримы, Discord и магазин доступны из лаунчера, но не перекрывают запуск игры.
5. Продвинутое — глубже, но доступно: память, Java, папка игры и консоль для опытных игроков.

## Accessibility & Inclusion

Анимация фона отключается при включённом в Windows уменьшении движения и останавливается, когда окно свёрнуто. Управление с клавиатуры поддерживается (видимый фокус, стрелки в выборе сборки, Esc закрывает окна). Отдельный стандарт доступности владельцем не задан.
